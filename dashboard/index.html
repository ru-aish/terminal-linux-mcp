Reading the numbers

Two ledgers, not one blended total.

Exact is provider-reported model usage. Cached input is shown as context, but it is already part of input tokens.

Estimated uses the GPT-5-family tokenizer on text visible to the MCP proxy: the tool call emitted by the model and the result returned to it.

These figures can overlap and should not be added together as a billable total.
